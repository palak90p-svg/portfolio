Featured project

AI Face Recognition System

Intelligent Customer Identification, Potential Duplicate Record Detection and AI-Assisted Data Correction

CITS Project Report · NSTI Kanpur · Trade: CSA · Instructor: Mohammad Kashif Siddiqui

An AI-based system that identifies returning customers using facial recognition and detects potentially duplicate customer records. It compares details such as name, phone number, email and customer ID, flags missing or inconsistent data, and suggests corrections.

Facial similarity alone does not prove identity, so every match and correction goes through human verification before the database is changed.

GitHub Live Demo Project Report (PDF)

The problem

The same customer can be registered more than once because of spelling mistakes, different phone numbers or incomplete information. Manual checking is slow and error-prone.

Objectives

  • Identify returning customers using facial recognition
  • Detect potentially duplicate customer records
  • Compare name, phone, email and customer ID
  • Identify missing, inconsistent or incorrectly formatted data
  • Suggest corrections with human approval before any update

My role & learning focus

  • Face detection using a camera
  • Face capture of a person's image
  • Face matching using facial features such as eyes, nose and lips

Responsible by design

  • Human verification before any change
  • Customer consent and biometric data security
  • No automatic merging or editing of records

How it works

  1. 1Customer registration with consent
  2. 2Image capture
  3. 3Face detection
  4. 4Feature extraction (embedding)
  5. 5Face matching
  6. 6Customer record search
  7. 7Duplicate detection
  8. 8Data quality analysis
  9. 9AI correction suggestions
  10. 10Human verification
  11. 11Database update with audit log

Technologies (proposed)
